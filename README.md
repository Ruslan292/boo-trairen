# БОО — тренажёр

Веб-приложение для подготовки по билетам безопасного обращения с оружием.
В базе **116 уникальных вопросов** из файла «Билеты БОО с ответами 2026.docx».
Из исходных 200 позиций удалены 84 полных дубля. Вопросы распределены в
**12 учебных билетов**: 11 по 10 вопросов и последний из 6. Тексты, варианты
и ключи ответов взяты из документа. Вопросы с одинаковой формулировкой и разными
вариантами ответов сохранены, поскольку проверяют разные правила.

## Возможности

- **Обучение:** все вопросы подряд или выбранный билет, проверка после каждого ответа.
  «Продолжить обучение» возвращает к сохранённой сессии или открывает ещё не
  изученные вопросы. Если выбранный билет уже пройден, продолжение открывает
  оставшиеся вопросы из других билетов. Оно доступно на обзоре, странице билетов
  и после результата обучения. В частично пройденном билете кнопка продолжения
  пропускает изученное; «Пройти заново» и «Повторить билет» явно запускают повтор.
- **Учебный экзамен:** выбранный или случайный билет, таймер, свободный переход
  между вопросами и результаты после завершения. Длительность — 5, 10 или 20
  минут; допустимое число ошибок — 0, 1 или 2. Это настройки тренажёра.
  Пропущенные вопросы считаются ошибками.
- **Работа над ошибками:** неверные и пропущенные ответы попадают в отдельный
  список. Правильный повторный ответ убирает вопрос из этого списка.
- **Сложные вопросы:** отмечайте вопрос звёздочкой в тренировке, разборе экзамена
  или списке ошибок. В отдельном разделе можно повторять коллекцию по кругу:
  после последнего вопроса начинается следующий круг. Правильный ответ не снимает
  отметку — вопрос остаётся в коллекции до ручного удаления. Отметка не меняет
  очередь ошибок: неверный ответ по-прежнему попадает туда, верный убирает его
  из очереди, а ваша коллекция сохраняется.
- **Прогресс:** у обучения, экзамена, работы над ошибками и сложных вопросов свои счётчики, точность,
  настройки и сохранённая сессия. Ответы в экзамене и повтор ошибок не увеличивают
  число изученных вопросов. Очередь ошибок общая, история хранит последние 50
  экзаменов. Данные хранятся в `localStorage` текущего браузера.
- **Продолжение:** четыре незавершённые сессии сохраняются после переключения режима
  и обновления страницы. Новая тренировка заменяет только сессию своего раздела.
  В сложных вопросах сохраняются номер круга и позиция в коллекции.
  Таймер экзамена продолжает идти, в том числе при закрытой вкладке; завершение
  фонового экзамена сохраняет открытое обучение или повтор на прежнем вопросе.
- Адаптивный интерфейс для телефона и компьютера. В обучении можно использовать
  клавиши `1`–`3` для ответа и `Enter` для проверки или перехода.

«Изучено» означает число уникальных вопросов, для которых уже проверен хотя бы
один ответ в обучении. Старый общий прогресс автоматически переносится в обучение:
при 60 изученных вопросах без сохранённой учебной сессии продолжение открывает
оставшиеся 56. Исходная запись сохраняется один раз в `boo-trainer:v1:legacy-backup`
перед переносом. Прежние попытки и ошибки для повторов автоматически объединяются.
История экзаменов сохраняет результаты исходных билетов, помечая их как
«Исходный билет»; незавершённые тренировки восстанавливаются без повторений.
Точность — доля правильных ответов среди всех проверенных попыток.

## Запуск

Нужен **Node.js 24** (в облачной среде уже доступен). Внешних npm-зависимостей нет:
установка пакетов и сборка не требуются.

```sh
cd /workspace/boo-trairen
npm start
```

Сервер раздаёт приложение из `public/` на порту **3000**. При необходимости:

```sh
PORT=8080 HOST=0.0.0.0 npm start
```

Сервер нужен только для выдачи статических файлов; приложение можно разместить
на статическом хостинге, разместив содержимое `public/` в корне сайта. Аккаунты,
серверная база и синхронизация между устройствами в текущей версии отсутствуют.

### Публикация на GitHub Pages

Файл `.github/workflows/pages.yml` проверяет приложение и публикует только
содержимое `public/` при отправке изменений в `main` или ручном запуске workflow.
В настройках репозитория **Settings → Pages → Source** выберите **GitHub Actions**.
После успешного выполнения шаг **Deploy** покажет адрес опубликованного сайта.
Для запуска публикации отправьте файлы приложения и workflow в репозиторий.
Относительные пути поддерживают размещение в подкаталоге репозитория.

## Проверки

Для проверки источника данных дополнительно нужен **Python 3.12**.

```sh
npm test
```

Команда запускает тесты логики тренажёра и сверку всех 200 вопросов и ответов
с исходным DOCX. Проверяется также отказ от извлечения при неверных ключах,
пропущенных строках или конфликтующих ответах.

Браузерная проверка использует Python Playwright и Chromium, доступные в текущей
облачной среде. При запущенном сервере:

```sh
python3 tests/browser_smoke.py
python3 tests/browser_difficult.py
```

Проверяются обучение, повтор ошибок, экзамен, ручные отметки сложных вопросов,
повторение по кругу, перенос старого прогресса и продолжение после 60 изученных
вопросов, независимое сохранение режимов, завершение фонового экзамена по таймеру
и мобильная раскладка.

## Обновление базы

Исходный документ не изменяется при извлечении. После его обновления:

```sh
npm run extract
npm test
```

Скрипт использует стандартную библиотеку Python, требует 20 билетов по 10
вопросов и явные ключи 1–3 в столбце «Верно». При несоответствии структуры
завершается с ошибкой, не заменяя существующую базу.

После проверки исходника скрипт удаляет полные дубли и формирует учебные билеты
по 10 уникальных вопросов (последний билет может быть короче). При сравнении
не учитываются регистр, лишние пробелы и конечный знак вопроса в формулировке.
Содержание и порядок вариантов ответов должны совпадать. Разные варианты
ответов остаются отдельными вопросами; несовпадающие ключи одинаковых вопросов
останавливают извлечение. Номера учебных билетов могут отличаться от исходных.

## Структура

```text
public/                    Статическое приложение
  app.js                   Интерфейс и обработчики действий
  dashboard.js             Обзор и отдельный прогресс четырёх режимов
  model.js                 Прогресс, сессии, подсчёт результатов
  questions.json           База, извлечённая из DOCX
scripts/
  serve.mjs                HTTP-сервер без внешних зависимостей
  extract_questions.py     Проверка и извлечение документа
tests/                     Проверки логики, источника и браузера
```
